    How Word Rocket Works

    Word Rocket is a sight word practice app built on the Kearns high-frequency word list (300 words). It uses spaced practice across days to build automatic, on-sight recognition.

    How a session works

    Each session flashes words on cards. Tap ✓ Correct if the student reads it right within the set time (3 or 4 seconds), ✗ Incorrect if they miss it, are too slow, or need to be told the word. The app then shows the word with a short script for teaching it. A miss on a new word starts its rehearsal over.

    Interleaving

    Practice uses incremental rehearsal: a new word is shown, then mixed with one known word, then two, then three, and so on. The known words come up in a random order each round so the student reads the word, not the pattern.

    Spaced repetition

    A word becomes Known after the student reads it correctly within the set time (3 or 4 seconds), every time it appears, on 3 practice days in a row. One miss or slow read resets the count. Known words keep showing up as the mix-ins for newer words.

    Word sets

    Each student works on a mission, a small set of new words to master. By default the teacher or parent enters the words with Choose Words: new words to learn, and words the student already knows. A teacher can instead switch a student to a flashcard assessment, which finds the student's next 7 missed words and can print practice and game cards for them. When a mission is complete, the student's page asks for new words. While a mission is in progress, the words can still be changed with the small Edit words link. Words are listed A to Z.
